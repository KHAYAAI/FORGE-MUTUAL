# Draft policies

Every file here is a DRAFT written for a board that does not yet exist. None is approved. They are written from what the repository does today so that they describe reality, with PROPOSED values the owner must accept or change. Approving them is a human act: the board, with advice from a lawyer, adopts each one and records the date on the file.

Drafts that are thin, because the regulation text was not read in full: the concentration policy and the fit-and-proper procedure. Not drafted: financial projections, and the recovery and resolution plan beyond the recovery plan outline.


The full list, with each policy's owner, approver and review cycle, is [`docs/governance/POLICY_FRAMEWORK.md`](../../governance/POLICY_FRAMEWORK.md). Drafts added on 2026-11-18 cover the board and committees, the risk framework and appetite, credit, capital, market and operational risk, compliance, internal audit, financial reporting and returns, cloud and offshoring, provider due diligence, continuity, IT risk, security testing, incident notification, conduct, whistleblowing, pay, ownership, naming, cash reporting, POPIA, complaints, product approval and the licence application plan.
